The first line names the format version:
    #version [decimal number 1-255 describing version]
For example:
#version 1

=== Version 1 (current) ===
CSV, one sample per row. Rows starting with # shall be ignored (except the first #version as described above)
No quoting and no escaping: a field never contains a comma, a quote, CR or LF.
Rows are separated by LF.
A # row after #version naming the columns of each fieldtype the file uses is recommended but not mandatory.

First field is cmd_id, a decimal number 1-255 that describes command id for this row

cmd_id 1 - Run
cmd_id                 1
left_speed             left wheel speed in percent, -100..100 (-100 = full reverse, 100 = full forward)
right_speed            right wheel speed in percent, -100..100
disc_speed             disc speed in percent, -100..100
force_run              1 = do not stop when hitting obstacles

cmd_id 2 - Turn
cmd_id                 2
wheel_speed            nominal wheel speed in percent, -100..100
turn_angle             angle to turn in degrees, 0..255
turn_dir               direction to turn, 0 = left, 1 = right
disc_speed             disc speed in percent, -100..100
force_run              1 = do not stop when hitting obstacles

cmd_id 3 - Wait 
cmd_id                 3
event                  0 = no event (only timeout), 1=turn complete, 2=rtkfloat or rtkfix, 3=rtkfix
timeout                timeout in seconds, 0-255

cmd_id 4 - Run to point
cmd_id                 4
latitude_nmea          verbatim NMEA ddmm.mmmmm; deg = floor(v/100), decimal = deg + (v - deg*100)/60
latitude_hemisphere    N or S; S is negative
longitude_nmea         verbatim NMEA dddmm.mmmmm; converted as latitude_nmea
longitude_hemisphere   E or W; W is negative
